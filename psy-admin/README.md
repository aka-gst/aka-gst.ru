# Psy AI Admin на aka-gst

Автономная демонстрационная страница безопасного помощника по открытым материалам центра «Орион».

## Адрес

После обычного развёртывания сайта страница доступна по адресу:

`https://aka-gst.ru/psy-admin/`

## Что нужно перенести на сервер

Скопировать каталог `psy-admin` целиком в `/srv/psy-admin` вместе с остальными статическими файлами сайта. В `Caddyfile` добавлен редирект с `/psy-admin` на `/psy-admin/`.

Страница не использует базу данных, платный AI API или внешний сервер проекта. Ответы и правила находятся в локальных файлах:

- `content.js` — описания программ, ключевые слова и официальные ссылки;
- `router.js` — выбор ответа и безопасные границы;
- `app.js` — интерфейс диалога;
- `test.mjs` — минимальная проверка ключевых сценариев.

## Проверка перед публикацией

Из корня сайта:

```sh
node psy-admin/test.mjs
python3 -m http.server 8094 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8094/psy-admin/`.

## Обновление информации

Даты, стоимость и наличие мест намеренно не зашиты в ответы. Для них помощник отправляет пользователя на актуальную официальную страницу. Краткие описания и ссылки следует периодически сверять с открытыми страницами центра.
