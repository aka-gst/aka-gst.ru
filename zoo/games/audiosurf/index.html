Трасса строится из вашей музыки: ритм становится поворотами, громкие места — плотностью блоков. Каждый трек даёт свою трассу.

Файл никуда не отправляется. Он разбирается прямо в браузере и остаётся на устройстве. Ни загрузки, ни сохранения на сервере.

Подойдёт mp3, m4a, wav, ogg — любой файл, который умеет проигрывать браузер. На айфоне доступны файлы из «Файлов»: треки из Apple Music защищены и не открываются ни в одном браузере.
