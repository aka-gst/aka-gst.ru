# YSI Companion local concept demo

Open `index.html` through a local HTTP server. This is a private, synthetic sales prototype.

It has no YSI account connection, analytics, payment processing, voice transmission, Telegram integration, real sync, or user data.

Key checks:

- The three assistant examples show a useful answer, a course-choice clarification, and a safe non-clinical refusal.
- The practice journal only changes in browser memory for the demo.
- The owner dashboard is labelled synthetic and is aggregate-only.
