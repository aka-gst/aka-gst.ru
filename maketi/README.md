# Макеты

Здесь лежат макеты — не выкладываются, в белый список выкладки не входят.

**Почему в репозитории, а не на столе.** 5 сентября 2026 макет первого экрана
жил файлом на Рабочем столе, был принят Глазами-Ушами по отпечатку
`26 240 байт / 01:25:23 / 6b641c66` — и к полудню **исчез**. Ни на столе, ни в
корзине, ни по содержимому нигде; симлинк из `trash/maket/` повис. Кто убрал,
неизвестно. Восстановлен по памяти сессии и сверен с принятым по числам:
строк на старте 6/3/11, верх первой +39/+30/+30, срезов нет, запас 33/31/274,
консоль чистая — всё совпало. Байты другие (24 599), потому что это
добросовестное восстановление, а не побайтовая копия.

**Вывод, ради которого написано:** файл, который кто-то принял, не должен жить
там, где его можно удалить молча. В репозитории удаление видно в `git status` и
откатывается одной командой.
