# Локальные направления для aka-gst.ru

Открыть через локальный сервер из корня worktree:

```sh
python3 -m http.server 4180
```

Адрес: http://127.0.0.1:4180/design-preview/

Это сравнительный прототип, не опубликованная главная. Изображения взяты из собственных `assets/shots` сайта. Кнопки «Открыть» ведут к существующим публичным маршрутам, а переключатели показывают три направления оформления.

Дальнейшее внедрение выбранного варианта — через `build.mjs`, `data/*` и общие стили, с проверкой 375/390/1440/2000 и затем отдельной сверкой на живом адресе.
