# Локальные направления для aka-gst.ru

После перезагрузки Mac запустите `___START.command` двойным щелчком и оставьте
окно терминала открытым. Если сервер уже работает, команда просто покажет адрес.

Или запустите из корня worktree вручную:

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4180/design-preview/

Это сравнительный прототип, не опубликованная главная. Страница по адресу выше показывает три самостоятельных направления:

- `01-systems.html` — инженерные работы на первом плане;
- `02-worlds.html` — игры на первом плане;
- `03-atelier.html` — авторское портфолио с литературой, играми и программами.

Иллюстрации на первых экранах «Систем» и «Миров» созданы специально для этих эскизов и не изображают уже готовые продукты. Ниже используются реальные кадры из `assets/shots` и обложки из `assets/covers`. Ссылки на проекты ведут к публичным страницам сайта; страницы дизайна существуют только локально.

Дальнейшее внедрение выбранного варианта — через `build.mjs`, `data/*` и общие стили, с проверкой телефона и компьютера, а после публикации — отдельной сверкой на живом адресе.
