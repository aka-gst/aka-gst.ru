# Новый aka-gst: работа / игры / рассказы

Локальный кандидат для просмотра. Главное меню содержит ровно три страницы:
`index.html` (работа), `games.html` (игры), `stories.html` (рассказы).
Отдельный кейс `game-design/` открывается из резюме и не добавляет четвёртую
вкладку. Запуск: `../___START.command`, затем
`http://127.0.0.1:4180/design-preview/site/`.

На первом экране работы стоят настоящие экраны Local Agent Gateway, ФотоДаты и
QueQuest. Ниже — подробные примеры, десять рабочих проектов и резюме. На первом
экране игр — запись ACID UNO и запуск; ниже видео NEON CLAW, Тетколора и Неон
Линий и полный каталог из 13 игр (включая QueQuest). Мобильный статус нельзя
приписывать каждой игре: некоторые проекты в каталоге требуют клавиатуры. На
странице рассказов — три сборника и 23 ссылки на полные тексты.

`build-content.mjs` обновляет каталоги и резюме из `../../data/projects.json`,
`../../data/site.json`, `../../data/stories.json` и точные рабочие фразы из
`../../data/frazy.json` (шесть дословных публичных фраз). После изменения
каталогов запустить `node design-preview/site/build-content.mjs` из корня репо.
Маркеры `GENERATED` должны оставаться по одному; генератор останавливается при
нулевом или двойном маркере. Источник живого сайта — корневые `build.mjs` и
`data/*`: этот кандидат не меняет сгенерированную главную живого сайта.

Кейс VitalSchool перенесён из
`/Users/gst/dev/_sites/vitalschool-game-design-portfolio/` (v5) без изменения
содержательных заявлений. Материалы: локальные скриншоты и внешние ссылки на
исходные видео и архив разработки. В шапку копии добавлена ссылка назад к
работам. Оригинальная папка на Desktop и отдельный проект в dev сохранены.

Направление оформления: реальный экран в первом кадре, крупная типографика и
простая иерархия. Изучены [Instrument](https://www.instrument.com/),
[Linear](https://linear.app/) и [Stripe](https://stripe.com/): у них сильная
иерархия и продукт виден до длинных объяснений. Их код, графика и шрифты сюда
не копировались. Для этого кандидата достаточно уже имеющихся кадров и клипов;
новые библиотеки или пакеты не требуются.

Шрифты Manrope и Literata поставляются локально с OFL-лицензиями в `fonts/`.
Кадры и клипы — из каталога этого репозитория. Обложки рассказов — из каталога,
где автором обложек указан Bizi. Перед публичным размещением новой версии
нужно отдельно сверить права на выбранные материалы и поведение игр на живом
сайте. Этот кандидат не опубликован.
