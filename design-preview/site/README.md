# aka-gst: работа / игры / рассказы

Локальный кандидат. Запуск: `../___START.command`, адрес:
`http://127.0.0.1:4180/design-preview/site/`.

Три раздела: тёмная зелёная работа, тёмные фиолетовые игры, рассказы с тёплой
типографикой. Главный рабочий кейс — QueQuest: первый экран, видео новой первой
смены, затем другие инструменты, каталог и резюме. Кейс VitalSchool открывается
из резюме и не создаёт четвёртой вкладки.

В каталоге шесть рабочих кейсов и семь браузерных демо. Ещё два инструмента и
шесть игровых проектов показаны отдельно как готовящиеся к публикации, без
неработающих кнопок. Архивные симуляции не показываются отдельными продуктами:
следующий общий проект — Глубина. Отложенные проекты не входят в витрину.

`content-policy.mjs` задаёт состав и порядок каталогов. `build-content.mjs`
обновляет их из публичных `../../data/projects.json`, `../../data/site.json`,
`../../data/stories.json` и шести дословных фраз `../../data/frazy.json`.
Содержимое рассказов — три сборника, 23 ссылки. Генератор требует ровно одну
пару маркеров для каждой секции.

Проверки:

```sh
node --test design-preview/site/content-policy.test.mjs
node design-preview/site/build-content.mjs
node --check design-preview/site/site.js
```

Анимации: появление секций, отклик карточек, переходы между страницами и короткий
глитч смены фраз. Ленту можно остановить; при `prefers-reduced-motion` глитч,
автоматическая смена фраз, фоновые движения и перемещение при переходах отключены.
В скрытой вкладке таймер ленты не работает. Без JavaScript тексты и ссылки видны.

## Материалы

- Manrope и Literata — локальные шрифты с OFL-лицензиями в `fonts/`.
- Снимки и клипы остальных проектов — существующие публичные материалы `assets/`.
- `quequest-warehouse-current.png` и `.webm` — новая запись собственного QueQuest
  16.3: обычный запуск первой смены, закрытие диалога начальника, движение WASD.
  Полное прохождение этой игры здесь не проверялось. Фрагмент не изображает
  работу роботизированной руки; описание её роли взято из README игры.
- QueQuest использует Kenney и Freedoom; собственные лицензии материалов остаются
  в исходном проекте. Скриншот и видео не содержат сторонних игровых референсов.
- Кейс VitalSchool сохраняет содержание собственного портфолио v5.
- Обложки рассказов — существующие материалы сайта; автор обложек указан Bizi.

Кнопка QueQuest в игровом каталоге открывает опубликованное демо курса. Оно
отличается от новой первой смены, показанной в рабочем кейсе. Браузерные ссылки
ведут на текущий публичный сайт: это не обещание, что все свежие локальные сборки
уже опубликованы. Перед обновлением живого сайта нужны отдельная проверка каждой
сборки и сверка прав на материалы. Авторская проверка вёрстки не заменяет
независимую приёмку и тест на физическом телефоне.

Источник живого сайта — корневой `build.mjs` и `data/*`. Этот кандидат не меняет
сгенерированную главную и не развёрнут на живом сайте.
