# Собранный сайт: работа / игры / рассказы

Локальный кандидат на основе выбранных Сергеем направлений 01 и 02. Здесь три
настоящие страницы с общей навигацией: `index.html`, `games.html`, `stories.html`.
Откройте `http://127.0.0.1:4180/design-preview/site/` после запуска
`../___START.command`.

Переходы между страницами используют нативные View Transitions, когда браузер
их поддерживает; без поддержки страницы работают как обычные ссылки. Появление
секций и немые видеофрагменты игр отключаются при `prefers-reduced-motion`.
Вся графика и шрифты загружаются локально; сторонних JS-библиотек и сетевых
зависимостей у прототипа нет.

`assets/system-hero.webp` и `assets/worlds-hero.webp` — специально созданные
концепт-иллюстрации, а не кадры существующих продуктов. Под ними использованы
реальные снимки и короткие видео из каталога сайта. Обложки рассказов взяты из
этого же каталога, где указан автор обложек. Перед публичным размещением нового
дизайна нужно проверить права на каждый выбранный визуальный материал.

Шрифты Manrope и Literata взяты из официального репозитория Google Fonts и
поставляются в оптимизированных WOFF2-наборах кириллицы и латиницы вместе с лицензиями `fonts/OFL-Manrope.txt` и
`fonts/OFL-Literata.txt`. Исходники: https://github.com/google/fonts/tree/main/ofl/manrope
и https://github.com/google/fonts/tree/main/ofl/literata.

Это прототип без изменений живого сайта. После утверждения переносить структуру
через `build.mjs` и `data/*`, а не менять сгенерированную главную вручную.
