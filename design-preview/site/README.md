# aka-gst: R5 preview, 3 октября 2026

Локальный кандидат по правкам Сергея, включая сохранённые изменения 2 октября.
Кэш-версия: `20261003-8`. Главный адрес:
http://127.0.0.1:4182/design-preview/site/?v=20261003-8

Если сервер остановлен, запустить `design-preview/site/___START.command`.
Он повторно использует работающий preview или запускает временный
статический сервер только на 127.0.0.1:4182 и открывает адрес в браузере.
При новом запуске показывает PID и команду остановки. Для проверки без
открытия окна: `___START.command --no-open`. Python 3 нужен на машине;
установки и изменения служб не выполняются.

Адреса разделов: `/design-preview/site/index.html?v=20261003-8`,
`/design-preview/site/games.html?v=20261003-8`,
`/design-preview/site/stories.html?v=20261003-8`. Пример reader:
`/design-preview/site/reader/myasnaya-konserva/?v=20261003-8`.

Основной фон #000. Шапка использует иконки и заполненные выбранные вкладки
старого сайта. ИИ-фраза находится в одной строке рядом с логотипом: набор
по букве, выдержка, стирание, редкий глитч. Подписи «(с)» и кнопки паузы нет.
EN — обычная ссылка. С reduced-motion фраза статична, видео остановлено.

На «Работе» сначала Local Agent Gateway и ANIGMA с реальными экранами,
затем большой QueQuest как учебный продукт и игра. Обе строки Сергея про
QueQuest берутся дословно из data/*.txt. Муха · Project Brain сохранена
как отдельная лаборатория обучения с подкреплением с публичным экраном;
ей не приписаны неподтверждённая версия или кнопка игрового демо.
Psy AI Admin и BEATDANCER сохранены на «Работе», блок резюме убран.

На «Играх» BEATDANCER стоит первым. Ролик ACID UNO — беззвучная визуальная
зарисовка, запускается inline и повторяется. Это анимация, не запись
геймплея. Название ролика и кнопки запуска/остановки убраны. Карточки
с существующими демо ведут к ним; проекты без проверенного демо остаются
без игровых ссылок. Вместо буквенных заглушек — предметные SVG-иконки.

На «Рассказах» три большие обложки ведут к сборникам. Все 23 рассказа
имеют миниатюру (14 собственных и 9 обложек сборника) и открываются в
локальном чёрном reader. Тексты взяты из original stories/*.txt без правок;
обложки и авторство взяты из data/stories.json. Есть оглавление и переходы
к соседним рассказам. Статистика чтения датирована сентябрём 2026;
обращения к текстам не объявляются дочитываниями.

Источники preview: build-content.mjs, content-policy.mjs,
catalog-additions.json, reader-content.mjs, site.css, site.js и три HTML
шаблона. Генератор обновляет отмеченные блоки и все страницы reader/*.
Корневой build.mjs и живой generated index.html не меняются.

```sh
node --test design-preview/site/content-policy.test.mjs design-preview/site/reader-content.test.mjs
node design-preview/site/build-content.mjs
node --check design-preview/site/site.js
```
