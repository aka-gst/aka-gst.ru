Атомарная цель. Получить доказанную карту входных точек, конфигурации, модулей и тестов без записи.

Что мы делаем и зачем

Карта репозитория отвечает на практические вопросы: откуда запускается сервер, где валидируется conf.yaml, где создаются LLM/ASR/TTS и какие файлы относятся к upstream baseline. Без этой карты легко исправить симптом в неправильном слое.

Что должно быть готово

  • Рабочая ветка подготовлена.
  • Репозиторий открыт именно из его корня.
  • Старые evidence и отчёты не нужны для анализа.

Где выполнять

Новая сессия Codex из C:\dev\agent-lab\Open-LLM-VTuber.

Откройте Codex из папки, указанной на предыдущей странице. Для независимого аудита обязательно создайте новую сессию. Скопируйте следующий prompt целиком, не вырезая ограничения.

PROMPT ДЛЯ CODEX - КОПИРОВАТЬ ЦЕЛИКОМ

Проведи read-only архитектурный обзор Open-LLM-VTuber.

Ничего не изменяй и не создавай. Не читай .env, evidence, .git, .venv, node_modules, старые логи и backup-файлы. Сначала прочитай README.md, CLAUDE.md или AGENTS.md, pyproject.toml, config_templates/README.md и quick-start документы, если они есть.

Покажи краткое дерево только релевантных каталогов. Затем укажи: серверную точку входа; команду запуска; конфигурационный слой; пользовательский conf.yaml; default templates; фабрики LLM, ASR и TTS; service context; WebSocket routing; frontend; Live2D; тесты и quality commands.

Каждое утверждение подтверди файлом и номером строки. Отдельно перечисли файлы, которые нельзя менять при upstream baseline. В конце выполни git status --short и объясни пустой вывод.

Команды PowerShell

Команды ниже нужны либо для ручного выполнения, либо для сверки предложения Codex. Строки после комментария «после подтверждения» не запускаются заранее.

КОМАНДЫ - КОПИРОВАТЬ ПО ПОРЯДКУ

rg --files -g README.md -g CLAUDE.md -g AGENTS.md -g pyproject.toml -g "*quick*" -g "!evidence/**"
rg -n "run_server.py|conf.yaml|tts_config|asr_config|llm_provider" README.md CLAUDE.md pyproject.toml src config_templates
git status --short

Как действовать при запросе разрешения

Прочитайте команду и рабочую папку; сразу сверьте их со scope этого эксперимента.

Для одной безопасной команды выберите разовое Yes, proceed.

Если команда читает секреты, пишет за пределами scope или меняет main - нажмите Esc и объясните ограничение.

Что должно получиться

  • Точка входа: run_server.py.
  • Verbose-команда: uv run run_server.py --verbose.
  • Схемы: src/open_llm_vtuber/config_manager/.
  • Frontend отмечен как Git submodule, если это подтверждено локально.

Типовые ошибки и действия

  • rg захватил evidence: повторить с -g '!evidence/**'.
  • Номер строки не подтверждает тезис: открыть узкий диапазон и перепроверить.
  • Агент предлагает менять код: отклонить, так как задача read-only.
