Атомарная цель. Зафиксировать точные допустимые значения LLM, ASR и TTS из Pydantic-схемы версии 1.2.1.

Что мы делаем и зачем

Названия backend являются контрактом. Строка, похожая на имя Python-класса, может не пройти Literal-валидацию. Поэтому значения нельзя угадывать по названию файла или старой инструкции: их берут из схемы установленного commit.

Что должно быть готово

  • Архитектурная карта указывает config_manager.
  • Никакие настройки пока не меняются.

Где выполнять

Read-only сессия Codex в корне репозитория.

PROMPT ДЛЯ CODEX - КОПИРОВАТЬ ЦЕЛИКОМ

Проведи read-only аудит backend-контрактов текущего Open-LLM-VTuber.

Ничего не изменяй. Прочитай только Pydantic-конфигурации LLM, ASR и TTS, default conf template и соответствующие factory-файлы. Покажи точные YAML paths и все Literal-значения для asr_model и tts_model. Отдельно подтверди наличие ollama_llm, openai_compatible_llm, sherpa_onnx_asr и pyttsx3_tts.

Для четырёх выбранных backend укажи: точное значение; YAML path; schema file:line; factory file:line; обязательные дочерние ключи. Не раскрывай содержимое пользовательского conf.yaml. В конце git status --short.

Команды PowerShell

Команды ниже нужны либо для ручного выполнения, либо для сверки предложения Codex. Строки после комментария «после подтверждения» не запускаются заранее.

git status --short

Как действовать при запросе разрешения

Прочитайте команду и рабочую папку; сразу сверьте их со scope этого эксперимента.

Для одной безопасной команды выберите разовое Yes, proceed.

Если команда читает секреты, пишет за пределами scope или меняет main - нажмите Esc и объясните ограничение.

Что должно получиться

  • ASR содержит sherpa_onnx_asr.
  • TTS содержит pyttsx3_tts.
  • LLM pool содержит ollama_llm и openai_compatible_llm.
  • Пути начинаются с character_config для ASR/TTS и agent_config для LLM.

Типовые ошибки и действия

  • Literal error: переписать значение ровно как в схеме.
  • Старый conf.yaml другой версии: не чинить шаблон, а классифицировать migration/configuration.
  • Комментарий template расходится со схемой: схема является источником истины для валидации.
